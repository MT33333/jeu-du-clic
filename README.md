# 🎮 Jeu du Clic

Un petit jeu web simple et rapide  
Le but : cliquer le plus de fois possible en 10 secondes ⏱️

👉 [Jouer en ligne maintenant](https://mt33333.github.io/jeu-du-clic/)  
*(fonctionne sur navigateur, mobile et ordi)*

---


##  Fonctionnalités

-  Interface intuitive
-  Enregistre ton **meilleur score**
-  Te félicite si tu bats ton record !
-  Effet sonore à chaque clic
-  Bouton "Rejouer" immédiat
- 100% HTML + CSS + JavaScript (aucune dépendance)

---

##  Comment l'utiliser
  
1. Clique autant que possible pendant 10 secondes  
2. Compare ton score et essaye de battre ton record !

---

##  Technologies

- HTML
- CSS
- JavaScript (vanilla)
- Stockage local avec `localStorage`
- Déploiement via **GitHub Pages**
